Questa pagina non è il sito.

Qui c'era una copia della home senza JavaScript: si vedeva, ma non rispondeva. Le fasi non cambiavano scorrendo, i trattini non facevano niente, le modali non si aprivano, i numeri restavano a zero. Non era il sito a essere rotto — era questa copia a non poter funzionare.

L'ho tolta. Il sito funziona, ed è verificato: sotto c'è come guardarlo davvero.

La strada breve

Rendere pubblico il repository

La pubblicazione automatica è già pronta e la costruzione riesce: si ferma solo perché piervanta-hash/idk è privato, e GitHub Pages sui repository privati richiede un piano a pagamento.

Su GitHub: Settings → General → Change repository visibility → Public. Da lì, entro un paio di minuti, il sito vive su piervanta-hash.github.io/idk/ e si apre da qualunque telefono, senza accessi. Ogni modifica lo aggiorna da sola.

La strada senza toccare niente

Farlo girare sul proprio computer

Serve Node.js da nodejs.org, versione LTS. Poi tre comandi: i primi due una volta sola. 

# scaricare il progetto
git clone -b claude/procedi-allegato-iaok0e \
  https://github.com/piervanta-hash/idk.git
cd idk

# installare (un minuto)
npm install

# avviare
npm run dev

Stampa un indirizzo, di solito http://localhost:3000. Per vederlo dal telefono sulla stessa Wi-Fi: npm run dev -- -H 0.0.0.0.

Sul sito pubblicato senza server c'è una sola cosa che non può funzionare, e lo dichiara: l'invio dei moduli. Quel pezzo ha bisogno di un server e delle credenziali di posta. Lì il modulo risponde che il messaggio non è partito e mostra l'indirizzo da copiare — non finge mai di aver spedito.
